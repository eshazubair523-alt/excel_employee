## Employee Data Analysis & Dashboard (Excel)

An end-to-end Data Analysis project built using **Microsoft Excel**, featuring data cleaning, Pivot Tables, interactive Slicers, and a comprehensive Dashboard to analyze employee performance, department-wise salaries, and workforce demographics.

## Project Overview
This project processes raw employee data to extract meaningful HR insights. It helps stakeholders understand salary distributions across departments, employee remote-work trends, performance scores, and status updates over the years (2020–2024).

 ## Tools & Techniques Used
 ## Microsoft Excel:
  * **Data Cleaning & Preparation**: Handled missing values, formatted columns (Phone numbers, Join Dates, Status), and resolved data anomalies.
  * **Pivot Tables**: Summarized large volumes of data for departmental salary averages and performance metrics.
  * **Interactive Slicers**: Added user-friendly filters for Performance, Remote Work, Status, Age, and Department.
  * **Data Visualization**: Designed multiple bar and column charts to represent statistical insights visually.

## Key Insights from the Dashboard
1. **Department Salary Trends**: Analyzed total and average salaries across various departments (Admin, Cloud Tech, DevOps, Finance, HR, Sales) (DevOps had the highest average salary at $86K).
2. **Workforce Status**: Tracked active, inactive, and pending employee statuses distributed year-over-year(Out of 1020 employees, 352 were Active).
3. **Remote Work Performance**: Evaluated performance scores categorized by remote-work status (True/False).
4. **Age Distribution**: Visualized employee age spreads across different organizational departments.
5. **Data Cleaning Note**: Cleaned incomplete phone numbers and handled missing N/A values in the Age column.
